# proverka-faktov
Скилл Codex «Проверка фактов»: сверяет ответ ИИ или черновик (письмо, отчёт, справку) с приложенными документами и ищет выдумку — у каждого утверждения статус «подтверждено», «противоречит» или «нет в источнике».

Установка — [INSTALL.md в prompt-helper](https://github.com/Automall-Training/prompt-helper/blob/main/INSTALL.md). Подробно, с примерами — плейбук команды Automall: https://automall-playbook.vercel.app
